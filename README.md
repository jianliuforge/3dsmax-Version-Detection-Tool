# 3dsmax-Version-Detection-Tool

一个用于检测 3ds Max 文件版本的 Python 工具，可以识别文件的主版本和另存为版本，并判断是否兼容目标版本。

## 功能特点

- 读取 3ds Max 文件（.max）的版本信息
- 检测主版本号和另存为版本号
- 支持多种编码格式解析
- 根据配置的目标版本自动判断兼容性
- 返回"通过"或"拒绝"状态

## 安装依赖

```bash
pip install olefile
```

## 使用方法

1. 修改 `check_max.py` 中的配置：
   - `MAX_FILE_PATH`: 设置要检测的 .max 文件路径
   - `TARGET_MAJOR`: 设置目标支持的最高主版本号（例如：23 = 2021, 26 = 2024）

2. 运行脚本：

```bash
python check_max.py
```

## 版本对照表

| 版本号 | 3ds Max 版本 |
|--------|--------------|
| 23     | 2021         |
| 24     | 2022         |
| 25     | 2023         |
| 26     | 2024         |

## 输出说明

- **通过**: 文件版本 <= 目标版本，可以使用
- **拒绝**: 文件版本 > 目标版本，不兼容

脚本会在拒绝时返回退出码 1，通过时返回 0。
